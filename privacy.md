# Privacy Policy

DopamineGuard does not collect, transmit, process, sell, or share any user data.

All settings, including blocked websites and custom messages, are stored locally within the user's browser using the browser storage API.

No information is sent to any server.

DopamineGuard does not use analytics, tracking technologies, advertising networks, cookies, or external services.

If this changes in a future version, this document will be updated accordingly.
