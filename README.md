# DopamineGuard

A simple, free, local-only website blocker for Brave, Chrome, and Chromium browsers.

No ads.
No accounts.
No tracking.
No subscriptions.

Your block list stays in your browser.

## Features

* Block distracting websites
* Custom block message
* Enable or disable blocking
* Local-only storage
* No external servers
* Open source

Default message:

> Get your dopamine from exercise and completing your projects, not this.

## Installation

1. Download or clone this repository.
2. Open Brave or Chrome.
3. Navigate to:

brave://extensions

or

chrome://extensions

4. Enable Developer Mode.
5. Click Load unpacked.
6. Select the DopamineGuard folder.

## Usage

1. Click the DopamineGuard extension icon.
2. Add one website per line.

Example:

facebook.com
youtube.com
reddit.com
x.com

3. Customize the block message if desired.
4. Ensure "Enable blocking" is checked.
5. Click Save settings.

## Privacy

All settings are stored locally in your browser.

DopamineGuard does not collect, transmit, store, or share any user data.
